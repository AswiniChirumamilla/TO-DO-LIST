# To-Do List Web App

Overview: This is a simple web-based To-Do List application that allows users to add, remove, and manage their tasks efficiently. The project is built using HTML, CSS, and JavaScript.

🔹 Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- User-friendly interface

🔹 Tech Stack
- HTML: Structure of the web application
- CSS: Styling for the UI
- JavaScript: Handles task interactions and logic

🔹 Installation & Setup
1. Download or Clone the Repository
   ```sh
   git clone <repository-url>
   ```
2. Navigate to the Project Directory
   ```sh
   cd TO-DO-LIST-main
   ```
3. Open `index.html` in a Web Browser
   - You can double-click the `index.html` file, or
   - Open a terminal and run:
     ```sh
     open index.html  # macOS
     start index.html  # Windows
     ```

🔹 Usage
1. Enter a task in the input field.
2. Click the "Add" button to add the task to the list.
3. Click on a task to mark it as completed.
4. Click the delete button to remove a task.
